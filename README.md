# Mi Rutina de Gym

**App:** https://guardvalker.github.io/gym-app/

Tracker de entrenamiento personal: rutina organizada por grupo muscular,
registro de series/repeticiones/peso por sesión, e historial guardado en el
dispositivo.

PWA de un solo `index.html` (HTML/CSS/JS vanilla, sin build step), instalable
en el celular, sin backend — todo se guarda en `localStorage`.
